# Full raw datasets

This folder contains GitHub-safe sample extracts of the raw input datasets. The complete raw files used locally are large and should not be committed directly to GitHub, because several exceed GitHub file-size limits.

Large local raw files include NYC Building Footprints, NYC Sidewalks, Address Points, Centerline, Parking Regulations, and PLUTO. Replace the sample files in this folder with the complete raw files before reproducing the full pipeline locally.
